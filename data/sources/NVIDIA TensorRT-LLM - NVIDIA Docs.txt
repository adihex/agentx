NVIDIA TensorRT-LLM

https://docs.nvidia.com/tensorrt-llm/index.html

NVIDIA TensorRT-LLM

https://developer.nvidia.com/tensorrt#inference

 provides users with an easy-to-use Python API to define Large Language Models (LLMs) and build 

NVIDIA TensorRT

https://developer.nvidia.com/tensorrt

 engines that contain state-of-the-art optimizations to perform inference efficiently on NVIDIA GPUs. TensorRT-LLM also contains components to create Python and C++ runtimes that execute those TensorRT engines.
